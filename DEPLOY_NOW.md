# Deploy Changes Now

Your code changes are on GitHub but **not deployed yet**. The GitHub Auto-Sync section exists in the code but won't appear until you deploy.

## Quick Deploy Steps

Run these commands to deploy:

```bash
# Build the project
pnpm run build

# Deploy to GitHub Pages (gh-pages branch)
pnpm run deploy
```

Or if you're using npm:
```bash
npm run build
npm run deploy
```

After deployment (1-2 minutes), refresh your site and the GitHub Auto-Sync section will appear in Settings → General tab!
