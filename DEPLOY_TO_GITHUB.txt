═══════════════════════════════════════════════════════════════════
  📦 DEPLOY YOUR PORTFOLIO TO GITHUB - COPY & PASTE COMMANDS
═══════════════════════════════════════════════════════════════════

STEP 1: CONFIGURE GIT (First time only)
────────────────────────────────────────────────────────────────────
git config user.name "Your Name"
git config user.email "youremail@example.com"


STEP 2: INITIALIZE GIT REPOSITORY
────────────────────────────────────────────────────────────────────
git init


STEP 3: ADD ALL FILES
────────────────────────────────────────────────────────────────────
git add .


STEP 4: CREATE INITIAL COMMIT
────────────────────────────────────────────────────────────────────
git commit -m "Initial commit: Modern portfolio with maintenance mode"


STEP 5: CREATE GITHUB REPOSITORY
────────────────────────────────────────────────────────────────────
1. Open browser: https://github.com/new
2. Repository name: portfolio-website
3. Visibility: Public
4. DO NOT check any initialization options
5. Click "Create repository"


STEP 6: CONNECT TO GITHUB (Replace YOUR-USERNAME and YOUR-REPO-NAME)
────────────────────────────────────────────────────────────────────
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
git branch -M main
git push -u origin main


EXAMPLE (if your username is "johndoe" and repo is "my-portfolio"):
────────────────────────────────────────────────────────────────────
git remote add origin https://github.com/johndoe/my-portfolio.git
git branch -M main
git push -u origin main


═══════════════════════════════════════════════════════════════════
  🌐 OPTIONAL: DEPLOY TO GITHUB PAGES (FREE HOSTING)
═══════════════════════════════════════════════════════════════════

STEP 7: ENABLE GITHUB PAGES
────────────────────────────────────────────────────────────────────
1. Go to your repository on GitHub
2. Click "Settings" tab
3. Click "Pages" in left sidebar
4. Under "Build and deployment":
   - Source: Select "GitHub Actions"
5. Click "Actions" tab to see deployment progress
6. Your site will be live at:
   https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/


STEP 8: UPDATE WORKFLOW FOR CORRECT BASE PATH
────────────────────────────────────────────────────────────────────
Edit file: .github/workflows/deploy.yml

Find the "Build" step and modify it to:

      - name: Build
        run: pnpm build
        env:
          VITE_BASE_PATH: /YOUR-REPO-NAME/

Replace YOUR-REPO-NAME with your actual repository name!


STEP 9: PUSH THE UPDATED WORKFLOW
────────────────────────────────────────────────────────────────────
git add .
git commit -m "Update base path for GitHub Pages"
git push

  🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

ERROR: "PowerShell scripts disabled"
SOLUTION: Use Git Bash or CMD instead of PowerShell

ERROR: "Permission denied"
SOLUTION: Check GitHub credentials or use personal access token

ERROR: "Repository not found"
SOLUTION: Verify remote URL with: git remote -v

ERROR: "Nothing to commit"
SOLUTION: Make sure you saved all files before git add

ERROR: 404 on GitHub Pages
SOLUTION: Check VITE_BASE_PATH matches your repository name
